# v1.5 实验计划：解除国家限制，最大频宽 + 最大功率

目标设备：小米 pudding / Qualcomm peach_v2 (qca_cld3_peach_v2, WLAN 5.2.1.146N)
硬约束：不断网（MCP 走独立链路）、不重启手机。

## 已确认事实（2026-11-05，root shell 实测）

1. phy#0 为 self-managed，`iw reg set <cc>` 不生效（驱动自管理监管域）。
2. `cmd wifi force-country-code enabled US` 生效路径已验证：
   - Framework: mOverrideCountryCode=US, mDriverCountryCode=US
   - Driver: phy#0 self-managed country US: DFS-FCC
   - 6GHz 5945-7105 @160/320 (NO-OUTDOOR) 已在监管域内解锁
   - UNII-2e (5490-5730 DFS) 与 UNII-4 (5855-5925) 解锁
   - 5GHz UNII-3 上限 30 dBm（CN 为 33，US 反而更低）
3. 当前功率受监管域钳制：6GHz 24 dBm、DFS 24 dBm。

## v1.5 设计方向（待 E1-E10 结果定稿）

1. 国家码策略保留并默认 US（已验证 6GHz+320MHz 解锁），新增 00(世界) 选项对比测试。
2. 功率策略分层：
   - L1 框架层: cmd wifi 可用功率接口（若存在）
   - L2 nl80211: iw phy set txpower（E3/E4 验证）
   - L3 WCNSS cfg 注入: 经 /data/vendor/wifi 覆盖路径写功率键（E5/E6 验证），
     需验证是否热生效或需 WiFi toggle（toggle 不断网，可接受）
   - L4 regdb.bin bind mount 替换（最后手段，E7 验证可行性与校验）
3. 所有覆盖动作幂等、可卸载恢复（uninstall.sh 清理 /data/vendor/wifi 注入文件与 mount）。
4. 每层动作后自动导出验证报告（iw reg get / iw phy / txpower 读回），写入 module.prop 描述。
